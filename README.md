# Article Project 📰

A clean and responsive multi-page blog layout built with **HTML** and **reusable CSS**. This front-end-only project showcases a **home page**, **blog grid**, and **individual article page**, all styled with modern and maintainable CSS techniques.

🌐 **Live Demo**: [agarticle-project.netlify.app](https://agarticle-project.netlify.app/)

---

## 📄 Pages

- **Home** – A welcoming landing page with a clean layout.
- **Blog** – Grid-based layout showcasing blog articles.
- **Article** – A styled, readable article content page.

---

## 🎨 Features

- Responsive design using **CSS Grid**
- CSS utility and reusable class naming
- Minimalist typography and layout
- Mobile-friendly (media queries)
- Fully accessible HTML semantics
